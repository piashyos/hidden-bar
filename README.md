# HiddenBar

Прячет значки строки меню на macOS 27. Всё, что левее шеврона `>`, скрывается, всё, что правее, остаётся на месте. Значки исчезают по-настоящему, а не уезжают в системное `«`.

## Возможности

- Клик по шеврону прячет и показывает значки.
- Режим «при наведении»: значки появляются, когда курсор наведён на шеврон, и снова прячутся через секунду после того, как он ушёл из строки меню.
- Правый клик по шеврону открывает меню «Настройки…» / «Выйти». Повторный запуск приложения тоже открывает настройки.
- Что прятать, решает положение значка: перетащи его с ⌘ левее или правее шеврона.

## Требования

- macOS 27, Apple silicon.
- Разрешение «Универсальный доступ»: через него HiddenBar узнаёт, где стоят значки. Запрос появится при первом нажатии на шеврон.

## Установка

1. Скачай `HiddenBar-<версия>.dmg` со страницы [Releases](https://github.com/piashyos/hidden-bar/releases), открой его и перетащи `HiddenBar.app` в «Программы».
2. Приложение не нотаризовано, поэтому при первом запуске macOS его заблокирует. Открой «Системные настройки → Конфиденциальность и безопасность» и нажми «Всё равно открыть».
3. Нажми на шеврон, разреши «Универсальный доступ» в открывшихся настройках и нажми на шеврон ещё раз.

## Сборка из исходников

Нужен Xcode 27.

```sh
./bundle.sh                                   # собирает build/HiddenBar.app
ditto build/HiddenBar.app /Applications/HiddenBar.app
```

`bundle.sh` подписывает приложение первым найденным сертификатом «Apple Development», а если его нет, то ad hoc. С постоянной подписью выданный «Универсальный доступ» сохраняется между пересборками; с ad hoc его придётся выдавать заново после каждой.

## Как это работает

На macOS 27 старый приём с растягиванием разделителя больше не работает: система отправляет такие значки в `«`. HiddenBar включает системное ограничение строки меню из режима экзамена (приватный фреймворк `MenuBarClientCore`): передаёт список приложений, которые нужно оставить, а остальные значки macOS убирает сама и перестраивает строку. Какие приложения стоят левее шеврона, HiddenBar узнаёт через Accessibility. Если HiddenBar закроется или упадёт, все значки вернутся.

## Ограничения

- Скрытие работает по приложениям: если у приложения несколько значков и хотя бы один стоит правее шеврона, видны все.
- Значки Пункта управления («Сейчас играет», индикатор микрофона) при показе появляются на долю секунды позже остальных: macOS создаёт их заново.
- Используется приватный API, и обновление macOS может его сломать. Тогда при попытке скрыть прозвучит сигнал, а значки останутся на месте.
- Интерфейс только на русском.
